# เตรียมเสียงต้นฉบับ

เสียงที่สร้างจะเลียนน้ำเสียง จังหวะ และเสียงรบกวนจากเสียงต้นฉบับมาด้วย เสียงต้นฉบับที่ดีจึงสำคัญที่สุด อัดหรือเลือกไฟล์ได้จากหน้าเว็บ ไม่ต้องคัดลอกไฟล์มาไว้ที่โฟลเดอร์นี้

- อัดเสียงพูดภาษาไทยตามธรรมชาติ 4 ถึง 8 วินาที ในห้องเงียบและเสียงสะท้อนน้อย หน้าเว็บอัดได้ไม่เกิน 15 วินาที
- วางไมโครโฟนห่างจากปากประมาณ 15 ถึง 25 ซม. และอย่าขยับระหว่างพูด
- ให้มีผู้พูดคนเดียว ไม่มีเพลง พัดลม เสียงพิมพ์ หรือเสียงแจ้งเตือน
- พูดด้วยน้ำเสียงและความเร็วที่อยากได้ในเสียงที่สร้าง หลีกเลี่ยงเสียงแตก การตะโกน และการกระซิบ
- จดประโยคที่พูดให้ตรงทุกคำ รวมคำซ้ำและคำอุทาน หรือกด **ถอดข้อความอัตโนมัติ** ในหน้าเว็บแล้วตรวจแก้
- กดเล่นเสียงต้นฉบับฟังก่อนสร้างเสียง เพื่อตรวจเสียงรบกวนและตรวจข้อความ
- เสียงที่สั้นกว่า 2 วินาทีหรือยาวกว่า 15 วินาทีจะสร้างเสียงไม่ได้ ต้องเลือกไฟล์ใหม่หรืออัดใหม่

ถ้าในเสียงต้นฉบับมีคำอังกฤษ ให้เขียนเป็นคำอ่านไทย เช่น `Good morning` เป็น `กูดมอร์นิ่ง`

ถ้าวางไฟล์ไว้ที่ `data/reference/user_voice.wav` หน้า Gradio รุ่นเดิม (`.\run-legacy.ps1`) จะเลือกไฟล์นี้ให้อัตโนมัติ ไฟล์ในโฟลเดอร์นี้ถูกกันไม่ให้ขึ้น Git

## โหมดอัดเสียง

กด **อัดเสียง** แล้วอนุญาตให้เบราว์เซอร์ใช้ไมโครโฟน พูดประโยคเดียวให้จบภายใน 15 วินาที แล้วกดหยุด หน้าเว็บจะเก็บเสียงเป็นไฟล์ WebM ไว้ในเบราว์เซอร์และให้ฟังได้ทันที ไฟล์จะถูกส่งเข้า backend เฉพาะตอนกดถอดข้อความหรือสร้างเสียง และ backend จะลบไฟล์ชั่วคราวเมื่อจบคำขอ

## การถอดข้อความ

ปุ่ม **ถอดข้อความอัตโนมัติ** ใช้ Thonburian Whisper ผ่าน `faster-whisper` บนเครื่องของคุณ ไม่ส่งไฟล์ไปบริการภายนอก การกดครั้งแรกจะดาวน์โหลดโมเดลราว 3 GB จึงนานกว่าครั้งถัดไป ผลลัพธ์แก้ไขได้เสมอ ควรตรวจชื่อเฉพาะและตัวเลขก่อนกดสร้างเสียง

ห้ามนำเสียงของผู้อื่นมาใช้โดยไม่ได้รับอนุญาต
