# เตรียมเสียงต้นฉบับ

วางเสียงของคุณที่ `data/reference/user_voice.wav` หรือเลือกไฟล์จากหน้าโปรแกรม

- อัดเสียงพูดภาษาไทยตามธรรมชาติ 4-8 วินาที ในห้องเงียบและเสียงสะท้อนน้อย (หน้าเว็บอัดได้ไม่เกิน 15 วินาที)
- วางไมโครโฟนห่างจากปากประมาณ 15-25 ซม. และอย่าขยับระหว่างพูด
- ให้มีผู้พูดเพียงคนเดียว ไม่มีเพลง พัดลม เสียงพิมพ์ หรือเสียงแจ้งเตือน
- หลีกเลี่ยงเสียงแตก การตะโกน และการกระซิบสำหรับตัวอย่างแรก
- จดประโยคที่พูดให้ตรงทุกคำ รวมคำซ้ำและคำอุทาน หรือกด **ถอดข้อความอัตโนมัติ** ในหน้าเว็บแล้วตรวจแก้ผลลัพธ์
- แนะนำ WAV mono 24 kHz หรือสูงกว่า; โปรแกรมรองรับ WAV, MP3, M4A, FLAC และ WebM
- หลังเลือกหรืออัดไฟล์แล้ว ให้กดเล่นเสียงตัวอย่างเพื่อตรวจเสียงรบกวนและตรวจข้อความก่อนกดสร้างเสียง
- เสียงที่สั้นกว่า 2 วินาทีหรือยาวกว่า 15 วินาทีจะแสดงคำเตือนและไม่ให้เริ่มสร้างเสียงจนกว่าจะเลือกไฟล์ใหม่

หากมีคำอังกฤษในเสียงต้นฉบับ ให้เขียนข้อความเป็นคำอ่านไทย เช่น `Good morning` เป็น `กูดมอร์นิ่ง` เพื่อช่วยให้โมเดลจับคู่เสียงกับข้อความได้ดีขึ้น

## โหมดอัดเสียง

กด **อัดเสียง** แล้วอนุญาตสิทธิ์ไมโครโฟนในเบราว์เซอร์ พูดประโยคเดียวให้จบภายใน 15 วินาที จากนั้นกดหยุด ระบบจะสร้างไฟล์ WebM ในหน่วยความจำของหน้าเว็บและแสดงเครื่องเล่นให้ฟังทันที ไฟล์จะถูกส่งเข้า backend เฉพาะเมื่อกดถอดข้อความหรือสร้างเสียง และ backend จะลบไฟล์ชั่วคราวหลังจบคำขอ

## การถอดข้อความ

ปุ่ม **ถอดข้อความอัตโนมัติ** ใช้ `faster-whisper` แบบ local ภาษาไทย โดยไม่ส่งไฟล์ไปบริการภายนอก การกดครั้งแรกอาจดาวน์โหลดโมเดลตามค่า `THAI_VOICE_WHISPER_MODEL` และใช้เวลานานกว่าครั้งถัดไป ผลลัพธ์เป็นข้อความแก้ไขได้เสมอ ควรตรวจคำไทย ชื่อเฉพาะ และตัวเลขก่อนใช้เป็น transcript

ห้ามนำเสียงของผู้อื่นมาใช้โดยไม่ได้รับอนุญาต
